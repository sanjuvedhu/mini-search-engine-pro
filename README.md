# 🔍 Mini Search Engine Pro

A DSA-intensive document retrieval system built using Python that simulates the core architecture of a search engine.

This project demonstrates advanced data structures and algorithms including Inverted Indexing, TF-IDF ranking, Boolean Query Processing, Heap-based Top-K selection, and Trie-based Autocomplete.

---

## 🚀 Features

- 🔎 Inverted Index for O(1) keyword lookup
- 🧠 Boolean Query Support (AND / OR / NOT)
- 📊 TF-IDF based relevance scoring
- 📈 Heap-based Top-K ranking
- 🌳 Trie-based prefix autocomplete
- ⚡ Multi-term query processing
- 📚 Clean modular architecture

---

## 🧠 Data Structures Used

- HashMap (Dictionary)
- Set operations (Intersection, Union, Difference)
- Heap (Priority Queue)
- Trie (Prefix Tree)
- Nested Dictionaries
- DFS Traversal
